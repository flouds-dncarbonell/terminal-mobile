# Créditos de terceiros

O Terminal Mobile reúne ferramentas independentes. Não há afiliação ou endosso dos respectivos autores.

| Componente | Autores / projeto | Licença / distribuição |
| --- | --- | --- |
| ttyd | [tsl0922/ttyd](https://github.com/tsl0922/ttyd) | MIT; instalado separadamente, binário não incluído |
| tmux | [tmux](https://github.com/tmux/tmux) | ISC; instalado pelo sistema |
| xterm.js e addon-fit | [xterm.js contributors](https://github.com/xtermjs/xterm.js) | MIT; arquivos em `web/vendor`, aviso em `xterm-LICENSE.txt` |
| marked 18.1.1 | [marked contributors](https://github.com/markedjs/marked) | MIT; `web/vendor/marked-LICENSE.txt` |
| DOMPurify 3.4.17 | [Cure53 e contribuidores](https://github.com/cure53/DOMPurify) | Apache-2.0 ou MPL-2.0; `web/vendor/dompurify-LICENSE.txt` |
| Space Grotesk | [Florian Karsten e autores](https://github.com/floriankarsten/space-grotesk) | SIL OFL 1.1; `web/vendor/Space-Grotesk-OFL.txt` |
| IBM Plex Mono | [IBM e autores](https://github.com/IBM/plex) | SIL OFL 1.1; `web/vendor/IBM-Plex-OFL.txt` |
| aiohttp | [aio-libs](https://github.com/aio-libs/aiohttp) | Apache-2.0 / MIT, conforme arquivos upstream |
| cryptography | [Python Cryptographic Authority](https://github.com/pyca/cryptography) | Apache-2.0 ou BSD-3-Clause |
| py-vapid e pywebpush | [web-push-libs](https://github.com/web-push-libs) | MPL-2.0 |
| 9router | [decolua/9router](https://github.com/decolua/9router) | MIT; instalado separadamente; patches locais não incluem builds ou contas |
| Codex CLI | [OpenAI](https://github.com/openai/codex) | Apache-2.0; instalado separadamente |
| Claude Code | [Anthropic](https://code.claude.com/) | Termos próprios; instalado separadamente |
| Playwright | [Microsoft](https://github.com/microsoft/playwright) | Apache-2.0; somente validação opcional |

As versões de xterm.js/addon-fit dos assets legados não estavam registradas na instalação original; não se atribui uma versão sem verificação. O aviso MIT desses componentes acompanha os arquivos. Dependências transitivas e ferramentas do sistema mantêm seus próprios avisos. Consulte os pacotes upstream para os termos completos de componentes não redistribuídos.
